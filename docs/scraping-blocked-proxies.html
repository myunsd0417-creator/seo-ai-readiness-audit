Getting blocked while scraping? When you need proxies (and when you don't)

Checking a few pages of your own site, or of a client's site, almost never needs proxies. Collecting thousands of pages from a site you don't control is different. Many sites limit how many requests one IP address can make, and once you go over that limit, you get blocked.

Proxies are not the first fix. Most blocks go away when you crawl more politely. This guide shows what to try first and how to tell when a proxy pool is really needed.

Signs that you are being blocked

What you seeWhat it usually means
429 Too Many RequestsYou are sending requests too fast. The site is rate-limiting your IP address.
403 Forbidden after a whileYour IP address or your request pattern was flagged.
A CAPTCHA or "verify you are human" pageBot protection is checking your traffic.
Pages that work in your browser but come back empty from your serverThe site treats data-center IP addresses differently from home connections.

Try these first (free)

  1. Slow down. Add a delay between requests and lower the number of parallel requests. This alone fixes most 429 errors.
  2. Respect Retry-After. When a 429 response includes this header, wait that long before trying again.
  3. Use a normal User-Agent. Some sites block requests that have an empty or obviously automated User-Agent.
  4. Only fetch what you need. Use the sitemap to find pages instead of following every link, and skip images and files you don't use.
  5. Check the rules. Read the site's robots.txt and terms. If a site does not allow automated access, proxies don't change that.
Proxies help when a site limits requests per IP address. They don't make it acceptable to collect data a site does not allow you to collect.

When proxies make sense

  • You need many pages from the same site, and even a slow crawl hits the per-IP limit.
  • You need to see a site the way it looks from another country (prices, search results, language versions).
  • Your server's IP address is blocked, but the same pages work from a normal connection.

A proxy pool sends your requests through many different IP addresses, so no single address goes over the limit. There are two common kinds:

TypeGood forTrade-off
Data-center proxiesMost sites, high volumeLower cost, but easier for strict sites to detect
Residential proxiesStrict sites, local resultsHigher cost per request

Start with data-center proxies and switch only the sites that still block you.
