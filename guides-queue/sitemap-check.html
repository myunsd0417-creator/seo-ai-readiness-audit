Is your XML sitemap actually working? A 5-minute check

A sitemap is a list of the pages you want search engines to find. It does not force anything into Google, but it helps crawlers discover new and updated pages, especially on large sites or sites with few internal links.

Sitemaps break more often than people expect: a plugin is removed, a migration changes the URL, or the file starts listing pages that no longer exist. Nothing on the website looks wrong, so nobody notices.

The 5-minute check

  1. Open it. Try https://yourdomain.com/sitemap.xml. Many CMSs use another name, such as sitemap_index.xml or wp-sitemap.xml. It should load as XML, not as an error page or your home page.
  2. Check robots.txt. Open https://yourdomain.com/robots.txt and look for a line like Sitemap: https://yourdomain.com/sitemap.xml. This is how crawlers find the sitemap without you submitting it anywhere.
  3. Spot-check the URLs. Open five URLs from the sitemap. Each should load normally, with no redirect, no 404 and no noindex.
  4. Check the count. Does the number of URLs roughly match the number of pages you want in search? Far fewer usually means sections are missing. Far more usually means tag pages, filters or test pages slipped in.
  5. Look at Search Console. If you use Google Search Console, open Sitemaps and check the status and the last read date.

Common problems and fixes

ProblemFix
The sitemap URL returns 404Turn the sitemap feature back on in your CMS or SEO plugin, then update robots.txt with the correct URL.
It lists redirected or deleted pagesList only final URLs that return 200. Regenerate the sitemap after a migration.
It lists noindex pagesRemove them. A sitemap should only contain pages you want indexed.
It uses the wrong domain (http, or without www)Use the same version of the domain as your canonical URLs.
lastmod is today's date on every pageOnly change lastmod when a page really changes. Google uses it when it is consistently accurate.
One sitemap file can hold up to 50,000 URLs (and 50 MB uncompressed). Larger sites split it into several files and list them in a sitemap index.

Summary

  • The sitemap should load as XML and be listed in robots.txt.
  • It should contain only working, indexable, canonical URLs.
  • Keep lastmod honest.
  • Re-check after every migration, redesign or plugin change.
