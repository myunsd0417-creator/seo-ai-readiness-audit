What is llms.txt? A plain guide to adding one to your site

llms.txt is a short Markdown file at the root of a website (https://yourdomain.com/llms.txt). It gives AI tools a clean summary of the site and links to the pages that matter most, without menus, ads or scripts.

It is a proposed convention, not an official standard. Some AI tools and developer platforms read it, and many sites now publish one. No search engine has said it uses llms.txt as a ranking signal, so treat it as a low-cost extra, not a replacement for good pages and an open robots.txt.

What goes in it

The usual structure is simple:

# Example Studio

> Web design studio in Lisbon. We build fast websites for restaurants and small hotels.

## Services
- [Website design](https://example.com/design): What we build and how long it takes
- [Pricing](https://example.com/pricing): Packages and what is included

## Help
- [Contact](https://example.com/contact): Email and opening hours
  • An H1 with the name of the site or company.
  • A one- or two-sentence summary in a quote block.
  • Sections with links to your most useful pages, each with a short description.

How to add one

  1. Write the file in a text editor and save it as llms.txt.
  2. Upload it to the root of your site, next to robots.txt. In WordPress you can use your host's file manager or an SEO plugin that supports it.
  3. Open https://yourdomain.com/llms.txt in a browser and check that it shows plain text.
  4. Update it when you add or remove important pages.
llms.txt does not control access. If robots.txt blocks AI search crawlers such as OAI-SearchBot or PerplexityBot, an llms.txt file will not change that. Check robots.txt first.

Common mistakes

  • Putting it in a subfolder. It belongs at the root.
  • Listing every page. Keep it to the pages a new visitor would need.
  • Linking to pages that redirect, return 404 or are noindex.
  • Losing it in a redesign or a move to a new host, which happens often.

Summary

  • llms.txt is a Markdown summary of your site for AI tools, placed at the root.
  • It is optional and cheap to add. It does not replace robots.txt or good content.
  • Keep it short, keep the links working and check it after redesigns.
